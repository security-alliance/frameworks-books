\chapter{Field cards}

These are prompts, not a binder. Customize
addresses and channels before the first real
operation.

\keepblock{%
\fontsize{8}{10}\selectfont
\setlength{\parskip}{0.65mm}
\colophonlabel{Before you sign}

Bookmarked Safe, full address.

Hardware wallet, dedicated profile.

``How to check'' arrived with the payload.

Independent hash matches the device. Entire hash.

Calldata decoded: function, target, params.

Simulation and decoder agree. Still use judgment.

No \texttt{DELEGATECALL} unless the module is
known.

``Checked, signed, X more.''
}

\vspace{2mm}

\keepblock{%
\fontsize{8}{10}\selectfont
\setlength{\parskip}{0.65mm}
\colophonlabel{Poisoned Safe / address book}

Dashboard can list a Safe you never created.

First four and last four characters matching is
not identity.

Navigate from a bookmark.

Never paste from explorer history or chat.

New recipient: tiny transfer both ways.

Large send: read the address on a video call.
}

\vspace{2mm}

\keepblock{%
\fontsize{8}{10}\selectfont
\setlength{\parskip}{0.65mm}
\colophonlabel{Compromise, 30 minutes}

Stop non-emergency transactions.

Notify every channel, including backup.

Scope the keys. Isolate devices.

New hardware, then rotate on-chain.

Lost key is not compromise. Still call the team.
}

\vspace{2mm}

\keepblock{%
\fontsize{8}{10}\selectfont
\setlength{\parskip}{0.65mm}
\colophonlabel{Pause-only}

The fast set may pause.

It may not upgrade.

It may not move funds.

Timelock bypass, if it exists, is this set, not
a quieter path to \texttt{upgradeTo}.

Drill it. Backup UI already practiced.
}
