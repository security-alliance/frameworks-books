\chapter{If it is happening now}

These are prompts, not a local emergency plan. Read them
before you need them.

\section{Before you sign}

\begin{enumerate}
  \item Official URL. Not a search result. Not a chat
  link.
  \item Contract address matches the docs.
  \item Function, destination, and amount match what you
  meant.
  \item Hardware screen agrees. If it does not, reject.
  \item Approval is the amount for this tx, not unlimited.
\end{enumerate}

\section{Seed may be exposed}

\begin{enumerate}
  \item Assume it is gone. Do not watch and wait.
  \item New wallet on clean hardware. New seed, written
  offline.
  \item Move funds. Then revoke what you can.
  \item Never reuse the old seed, device, or browser.
  \item Tell anyone who held a copy.
\end{enumerate}

\section{Approval or permit looks wrong}

\begin{enumerate}
  \item Reject. Close the tab.
  \item \texttt{spender} / \texttt{value} /
  \texttt{deadline} is not a login.
  \item Ignore mystery tokens. Do not claim them.
  \item Check remaining approvals from a machine you
  trust.
  \item If value already moved, this becomes incident
  response, not a retry.
\end{enumerate}

\section{Hardware arrived wrong}

\begin{enumerate}
  \item Pre-set PIN or pre-written seed: do not use it.
  \item Conference gift, marketplace, or reseller:
  same.
  \item Stop. Buy direct. Verify authenticity.
  \item Generate on the new device. Dry-run recovery.
  \item Move funds only after the replacement signs.
\end{enumerate}
