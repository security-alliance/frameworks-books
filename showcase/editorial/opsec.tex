\chapter{Operational security}

OpSec is a cycle. Name what would hurt if it leaked.
Name who wants it. Find the holes. Apply controls that
match the risk, then do it again. A policy binder nobody
runs is not OpSec.

This is the everyday layer: devices, browsers, passwords,
MFA, travel. Cryptography does not save a laptop left
unlocked in an airport lounge.

\section{Insights}

\begin{itemize}
  \item Layered controls. One lock failing should not
  dump the keys.
  \item Least privilege. Accounts get the access the job
  needs, then it gets taken back.
  \item Isolate work. Signing does not happen in the
  same browser that reads Discord.
  \item Web3 is public. The chain shows what you did.
  Your chat should not.
\end{itemize}

\section{Quick wins}

\begin{enumerate}
  \item Hardware key for MFA. SMS recovery is a SIM-swap
  waiting.
  \item Password manager. Unique secrets. No shared root
  accounts in chat.
  \item Separate browser or OS profile for signing.
  \item Before a trip, read the OpSec While Traveling
  companion.
\end{enumerate}

The full OpSec framework is on the site. Travel is its
own pocket book.
