\chapter{Awareness}

Awareness is recognizing risk signals early, especially
unexpected requests and urgency tricks, so tools are not
the only line of defense.

Culture fails when only scanners are expected to notice
danger. A hurried ``can you just sign this'' from a
known name is still an attack until you verify it on
another channel.

\section{Insights}

\begin{itemize}
  \item Pause is a control. Attackers buy speed.
  \item Out-of-band verification beats a perfect-looking
  email.
  \item Skills decay. Last year's phishing talk does not
  cover this week's drainer.
  \item Peer support. People miss things alone that a
  second person would catch.
\end{itemize}

\section{Quick wins}

\begin{enumerate}
  \item No signing, payouts, or admin changes from a
  single chat message.
  \item Call the person on a number you already had.
  \item Recurring, short drills beat a yearly slideshow.
  \item Reward the person who slowed a bad request down.
\end{enumerate}
