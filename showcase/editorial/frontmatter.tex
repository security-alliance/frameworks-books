\chapter{About this book}

This mini-book is a print map of the
\textbf{Security Frameworks}, an initiative by the
\textbf{Security Alliance}. The site is the living
document. This edition is rewritten for a pocket you can
hand to a founder, a signer, or a new hire on day one.

It is not every page. It is the 101 of the frameworks
that are actually built: takeaway, a few insights, the
first moves. Dev-gated stubs, tool catalogs, and
unfinished sections stay on the website. Empty chapters
make a worse companion than a short one.

Four other pocket books already exist. Coercion lives in
Physical Security. Travel lives in OpSec While Traveling.
Protocol signers live in Protocol Multisig. Self-custody
lives in Wallet Security. This book will not pretend to
be those.

This print cut changes order, cuts website navigation,
and turns the same controls into reading you can do on a
train. It does not invent new controls to fill gaps.

\chapter{How to use this}

The frameworks exist because the same losses keep
happening: a seed photographed, a Discord admin hijacked,
a dependency swapped, a signer who clicked the first
hash they saw. Cryptography did not fail. The rest of
the system did.

Read this as a map, not as a certificate. Each chapter
is one framework. If a chapter names a dedicated
companion, that companion is the deep cut. If it names
the site, go there before you copy a control into
production.
