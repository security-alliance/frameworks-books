\chapter{Physical security}

Physical security protects people and assets from threats
that bypass cryptography: coercion, theft, surveillance,
tampering. OpSec hides information. This domain stops
what a body can be forced to do.

A hardware wallet is useless if the person holding it is
in a room with a wrench. Life first. Then keys.

Coercion and duress is the mature core. Facility,
counter-surveillance, and hardware provenance pages are
still in progress on the site. This book will not fake
them.

\section{Insights}

\begin{itemize}
  \item One person should not be able to move the pile.
  \item Delay beats panic. Time-locks and extra signers
  exist so a kidnapping is not an instant drain.
  \item Families, homes, and routines are part of the
  threat model. Attackers map those first.
  \item If it is happening now, compliance is not the
  goal. Survival is.
\end{itemize}

\section{Quick wins}

\begin{enumerate}
  \item Know who can spend if you disappear for a day.
  \item Do not keep the seed where you sleep if that is
  also where you are found.
  \item Practice a duress path before you need one.
  \item Hand the Physical Security companion to anyone
  who holds a key worth coercing.
\end{enumerate}
